# AFN WIKI

**万物互联，让数据随心流动。**

Create: Advanced Frequency Network

**AFN 1.8.2 · Minecraft 1.21.1 · NeoForge · Create 6.0.0+**

让无线红石同时传递信号和信息：用分层频率管理设备，用信箱读取仪表和改写机器，用可拼接屏幕构建控制台，再用地图终端、寻呼机和电脑接入同一套信道。

客户端与服务端都需要安装 AFN。基础功能需要 Create；CC:Tweaked、Synaxis、Xaero World Map、航空学、创意传动等集成在装有对应模组时提供。

## 用频率组织无线红石信号

### 从一个频率开始

1. 右击频段板，填写 `factory.line_1.motor`。
2. 把板放入 Create 无线红石信号终端的频率槽。两端的另一个槽位也要匹配；普通物品可以充当副频。
3. 给发送端红石充能，接收端便可响应。发送端也可以用 `factory.*.motor` 选择多个地址。
4. 需要传递内容时使用信箱或桥接器；需要限制权限时使用鉴权频段板。

悬浮容器中的频段板并按 **空格**，可以直接编辑。频段板是配置凭证，不是消耗品。

### 频率、鉴权与长信号

地址用 `.` 分层。一块板保存主频和最多五个别名；接收规则可以选择 OR 或 AND。

| 发送端选择器 | 含义 | 示例 |
| --- | --- | --- |
| `?` | 当前层的一个字符 | `line_?.motor` |
| `*` | 当前层的任意字符 | `factory.*.motor` |
| `**` | 零层或多层，独占一个层级 | `factory.**.motor` |
| `[A-C]` | 当前层的一个集合字符 | `factory.line_[A-C]` |
| `!` | 排除当前层的指定项，可连续添加 | `factory.*.!private!test` |

**发送端写选择器，接收端写具体地址。** 接收板开启跨层响应后，较短发送地址可以覆盖更深接收地址。含 AFN 板的双槽匹配不区分槽位顺序，但两个槽都要匹配；纯 Create 物品双槽保持原生顺序。

鉴权频段板增加所有者、读取 / 读写共享权限、隐藏鉴权频率和安装锁。频率相同仍需通过身份准入；普通板没有所有者限制。界面和护目镜只显示玩家有权读取的信息。

长信号默认关闭，开启后可以在**同维度**跨距离通信，并按需唤醒未加载的接收设备。两端都要开启并配置有效鉴权板。额度按“设备 × 鉴权板所有者”计算：默认每位所有者 15 台，同设备、同所有者的多信道只计一次，实际额度以服务器配置为准。桥接器从各信道的真实频率槽取得资格，无需在本体另装鉴权板。

## 用信箱传信

### 什么是信道

信道把主频、可选副频、可选内容与激活状态放在一起。频率决定消息送到哪里，内容可以是文本、布尔值或有限实数组，激活强度为 0～15；改写内容与激活发送是两件事。在桥接器等多信道设备中，还可用信道名区分和引用各条信道。

### 信箱

信箱用同一套频率规则收发强度和内容，提供收信、发信、收发三种模式；收发模式不会把收到的信号直接回送。潜行右击打开配置，编辑收发模式与信箱内容。定向收信箱按入射角接收，调制收信箱根据发送端距离改变接收强度。

物流收信箱接收物资清单并向绑定的 Create 物流网络下单；存量信箱读取指定容器或物流网络中指定物品的数量，可输出数组、JSON 或 Map。

### 发出第一条消息

1. 放置两台普通信箱，把设为 `workshop.notice` 的频段板分别装入两端频率槽；另一个频率槽也保持一致。
2. 潜行右击发送端，设为“发信”，填写 `仓库在线` 并确认；把另一台设为“收信”。
3. 给发送端红石充能，接收端便会收到强度与内容；打开接收端配置，可看到 `仓库在线`。
4. 修改内容后再次激活，即可发送新消息。若希望提交修改便发信，再开启“修改后立刻激活”。

收到的内容可以继续交给输出语法处理；要将结果写进显示器或机器，再使用下一节的自动输出。

### 信道输出语法

输出语法提取、转换和计算数据，不改写原始内容。仅有一个 `${...}` 表达式时保留结果类型；与文字混排时得到文本。

```text
${number($[0])}
库存：${$.items[0].count}
{"deposit_positions_absolute":[[${$[0]},${$[1]},${$[2]}]]}
```

信箱 / 隐藏终端的 `$` 指本设备接收内容；普通文本用 `$[0]` 取得整段文字。桥接器用 `${信道名}` 或函数参数 `$.信道名` 引用本机信道。数组下标从 **0** 开始。引用自身读取原始值，引用其他信道读取有效输出。

下表列出全部 **33 个函数**，其后附有输入、表达式与输出示例。

| 用途 | 函数 |
| --- | --- |
| 缺值与类型 | `default`、`exists`、`type`、`size` |
| 转换 | `number`、`unit_number`、`text`、`boolean`、`json`、`game_time` |
| 数组 | `sum`、`avg`、`min`、`max`、`join` |
| 文本 | `substr`、`contains`、`starts_with`、`ends_with`、`replace`、`split`、`trim`、`lower`、`upper` |
| 计算 | `add`、`sub`、`mul`、`div`、`round`、`clamp` |
| 分支 | `if(test,yes,no)`、`switch(value,match,result,...[,default])` |
| 信号转信息 | `strength($)` 或 `strength($.信道名)` |

```text
${add($.燃料1,$.燃料2,$.燃料3)}
${number($.应力[0])}
${if($.开关,"运行中","已停止")}
${switch($.模式,0,"停止",1,"前进","未知")}
${strength($.传感器)}
```

| 示例输入 | 表达式 | 输出 |
| --- | --- | --- |
| `燃料1=2`、`燃料2=3`、`燃料3=5` | `${add($.燃料1,$.燃料2,$.燃料3)}` | `10` |
| `"1,234,211 su"` | `${number($[0])}` | `1234211` |
| `开关=true` | `${if($.开关,"运行中","已停止")}` | `运行中` |
| `模式=1` | `${switch($.模式,0,"停止",1,"前进","未知")}` | `前进` |
| 接收强度 `7` | `${strength($)}` | `7` |

`switch` 的文本匹配示例：`${switch($.模式,"前进","运行","停止","待机","未知")}`，输入 `模式="前进"` 时输出 `运行`。完整函数卡还列出每个函数的输入、输出和边界。

以上示例中，燃料和模式是原生数值信道，开关是布尔信道，应力是文本信道。`add` 支持多个参数，原生单数字信道不必加 `[0]`；JSON 数组即使只有一项也需下标，多项数组需下标或聚合。`number` 提取文本第一个数字并忽略其千位逗号，`1,234,211 su` 得到 `1234211`。`if` 的条件须为布尔值；`switch` 严格区分数字与文本；两者只计算选中的结果分支。精确参数规则、JSON 路径与可复制示例见 AFN WIKI。

### 激活条件与强度

信箱、存量信箱和桥接器分别提供适用的定时发送、修改后立即激活、条件激活和输出强度配置。改值与激活是不同操作，只有启用对应功能才会联动。

信箱条件示例：内容为 `{"temperature":32,"ready":true}` 时，按字段判断：

```text
${$.temperature} ≥ 30 & ${$.ready} = true
```

桥接器也可按信道名引用，例如 `${温度} ≥ 30 & ${开关} = true`。信箱无线收到的内容不触发条件激活或修改后脉冲。

条件支持比较、`&` / `&&`、`||` 和括号，留空关闭。输出强度接受数字或输出语法，限制在 0～15；留空跟随触发来源，没有外部强度的本地自动激活使用 15。普通信箱的输出强度规则可用 `${strength($)}` 换算原始接收强度；隐藏终端可在内容输出语法读取接收强度，但当前输出强度框不接受这个自引用。桥接器条件 / 强度规则有自身强度反馈保护，应读取独立输入信道。

## 万物互联

信箱把设备读数带进信道，再将内容交给显示器和机器配置。自动读取、输出语法与自动输出可以串起这条信息流。

### 设备一览

手持扳手潜行右键可拆下 AFN 方块。

| 发票机、验票机、鉴权刷卡机、身份验证柱 | 签发 / 验证票券，执行身份准入并输出红石 |

### 自动读取

“自动读取”把附着设备的数据读入信箱；“自动输出”把收到的当前内容写给附着设备。同一台信箱不能同时开启两者。在 GUI 的下拉列表中勾选读取项与模式，可全选，至少保留一项。

单选保留原始文本；多选输出 JSON，键优先用字段名，如“总应力容量”，用 `${$.总应力容量}` 读取。重名时加来源前缀，空白与标点改为下划线。数字、布尔值及标准 JSON 对象、数组保留类型，其他内容作为字符串。多选结果超过 1024 个字符或 4096 字节时输出 `{"error":"content_limit"}`，不截断 JSON。

| 读取对象 | 可以读取的内容 |
| --- | --- |
| 转速表、应力表 | RPM；应力进度条、百分比、当前 / 总计 / 剩余读数 |
| 智能侦测器、存量转信器 | 物品 / 流体数量或列表、容器填充比例 |
| 辉光管；传送带 / 置物台 | 显示内容；当前物品名称 |
| 布谷鸟钟；列车站 / 侦测器；升降机触点 | 时间；列车概况 / 名称；当前楼层 |
| 工厂仪表；座椅 | 连接面板的存量与请求状态；乘客名称 |
| 仓储发报机、仓储链接站 | 所属物流网络的 AFN 名称 |
| 创想附加蓄电池 | 精确整数 FE：储能、总容量、剩余容量；百分比或进度条 |
| 柴油动力引擎、化学炮塔、可控燃烧室、抽油机油泵 | 引擎实际RPM、方向、运行、当前SU容量与燃料；炮塔角度、喷射与流体；燃烧室开度、热量、输出强度；原油储量B |
| 飞控学导航终端（0.8.3 起） | 当前目标序号（从 1 开始）、目标世界坐标 x,y,z、当前线段完成百分比 0～100 |
| 网络音乐机：唱片机、播音喇叭 | 唱片播放、曲目、估算进度与歌词；广播地址、名称、范围与播放状态 |

航空学设备还可提供高度、速度、角度、探测结果、导航和气体等读数。实际目录取决于安装的模组，见 AFN WIKI 与游戏内帮助。
飞控导航终端的三项数据可同时读取；无有效目标时坐标为空，跟随、持续盘旋等没有明确线段完成率的状态不输出进度。

### 自动输出

显示目标接收文字，机器配置目标接收裸值或 JSON；隐藏终端默认具备同一套输出适配。

| 输出对象 | 示例内容 | 作用 |
| --- | --- | --- |
| 辉光管、翻牌显示器 | `仓库在线` | 显示文字；翻牌还支持分段宽度、颜色和轮换 |
| 转速控制器 | `128` 或 `{"speed":128}` | 调整目标转速 |
| 创想附加电动马达 | `-64` 或 `{"speed":64,"direction":"reverse"}` | 调整整数 RPM 与方向，0 停转；范围、供电与红石启停遵守本体规则 |
| 柴油动力三类引擎、动力曲轴 | `1` 或 `{"direction":"counter_clockwise"}` | 修改方向；模块整组、大型同轴联动 |
| 柴油动力化学炮塔 | `{"yaw":90,"pitch":-20,"spray":true}` | 平滑瞄准并持续喷射；发送 `{"spray":false}` 关闭 |
| 柴油动力可控燃烧室、抽油机曲柄 | `{"burn_rate":0.5}`；`{"size":"large"}` | 设置0～1阀门开度；修改曲柄尺寸 |
| 打包机 | `{苹果:4}` | 从连接库存打包清单 |
| 物流蛙港、邮箱 | `{"address":"码头"}` | 修改包裹地址 |
| 仓储发报机、仓储链接站 | `{"network":"main"}` | 切换命名物流网络，同名并网 |
| 动力锯、工作盆 | `{"result":"苹果"}` | 按结果物品筛选配方，材料与加工条件仍须满足 |
| 动力臂 | `{"deposit_positions_absolute":[[120,64,-30]]}` | 动态替换范围内的放置点 |
| 可编程齿轮箱 | 程序文本或 `steps` JSON | 替换动作程序 |
| 音符盒、播音喇叭及附属设备 | 对应字段文档 | 调整音高 / 播放和机器配置 |

动力臂的 `take_positions` / `deposit_positions` 是**相对动力臂的位置**；带 `_absolute` 的字段是世界坐标。提交某一侧的列表会替换该侧全部点位，未提供的另一侧保持不变；搬运中修改会等到空手后应用。物品筛选支持注册名、简写路径和唯一的本地化名称。

#### 动态过滤器

动态过滤器装入过滤槽后接收规则，手持时不接收。支持物品名称、注册 ID、标签与 Create 属性。空规则不放行；写入成功整体替换，非法文档保留旧规则。

```text
{苹果, 面包}
tag:minecraft:logs
mode:disj
```

带数量的存量 Map 进入限额通过模式，每次放行扣剩余数量，再次写入重置额度：

```text
{苹果:2, minecraft:bread:1, #minecraft:logs:5}
```

### 网络音乐机

唱片机可分别勾选：播放状态、歌名、歌手、译名、唱片时长、已播时长、剩余时长、播放进度、当前歌词、全部歌词、歌曲地址、循环播放、红石状态、VIP 歌曲、只读唱片、存在唱片。单项原样输出，多项合为 JSON；未勾选的读数不取样、不请求歌词。

时长单位为秒，进度为 0～100 的百分比；已播、剩余与进度均由服务端倒计时估算，不是精确音频时间。歌词仅适用于其支持的网易云歌曲，勾选后才异步获取并缓存，未获得或无歌词时为空；全部歌词超过 1024 字符或 4096 字节时输出“歌词超出信道长度限制”，不截断歌词。

```json
{"歌名":"示例歌曲","歌手":"示例歌手","播放状态":true,"播放进度":25}
```

播音喇叭仍可读取广播地址、名称、范围与播放状态，也可通过自动输出配置 `state`、`source`、`name`、`range`。

## 更多信道设备

### 桥接器

当前桥接器是可横纵拓展的黄铜机壳屏幕。旧 CRT 桥接器与旧大型桥接器仅保留存档迁移用途，不是当前推荐设备。

同向方块组成完整矩形屏幕，缺口不会被当作完整大屏。蹲下右击打开编辑 GUI，普通右击操作屏幕。每信道可分配一个不重叠矩形，没有旧的 4×4 选区限制。

| 模式 | 显示与操作 |
| --- | --- |
| 默认 / 文本 | 内容与可点击选项 |
| 开关 | 单值或数组分量，兼容布尔文本与 0/1 |
| 柱状图 | 自适应横向 / 纵向柱，配置分量名称和范围 |
| 仪表盘 | 多分量仪表，自适应居中排版 |
| 地图 | Xaero / AFN 地形或网格，多点、命名折线与面、收藏、实体目标和动态旋转 |
| 物流 | 独立配置多组物品、数量和地址，在屏幕选择发送 |
| 存量 | 物品图标与右下角数量，解析存量 JSON / Map |
| 对话 | 寻呼机消息，最新一条或滚动历史，以及简单回复 |

名称、待机状态、交互、修改确认和控件 / 背景 / 其他前景颜色可独立配置。“表现输出语法”展示计算结果并禁用屏幕交互。配置与数据可通过 `.bridge` 文件导入导出，屏幕布局不导入。

地图滚轮以聚焦点缩放，中键拖拽平移，重定向恢复合理视野。草稿确认前保持视野；提交和外部坐标 / 自身位置变化后，仅自身点或目标点越界时自动适配。GUI 实体选项控制对应屏幕按钮是否出现，附近点击可吸附已启用目标。

#### 地图数据格式

坐标统一为世界 `x,y,z`。单点可写 `0,64,0`；多个点支持按三项分组的扁平数据 `0,64,0,32,64,16`，也支持多维数组：

```json
[[0,64,0],[32,64,16]]
```

命名点可写 `{"name":"仓库","position":[0,64,0]}`，也可直接使用 `x`、`y`、`z` 字段。点、线、面可混合或独立定义，各自的 `name` 会显示在地图上：

```json
{
  "points":[{"name":"仓库","color":"#FF7043","text_color":"#FFE0B2","position":[0,64,0]}],
  "lines":[{"name":"路线","color":"#66BB6A","text_color":"#DCE775","points":[[0,64,0],[32,64,16]]}],
  "areas":[{"name":"作业区","color":"#42A5F5","text_color":"#B3E5FC","points":[[0,64,0],[32,64,0],[32,64,16]]}]
}
```

`color` 控制图形色，`text_color` 控制名称色，推荐使用 `#RRGGBB`。未填时分别沿用桥接器对应配色；线、面的顶点默认继承图形配色，显式顶点配置优先。也支持 `#RGB`、`0xRRGGBB`、十进制 RGB 整数和 `[r,g,b]`。

线至少两个顶点，面至少三个顶点，按给定顺序连接；`areas` 也可写成 `polygons`，`lines` 和 `areas` 中均可放多个图形。出现线或面时，原有“自身到目标”连线配置不再生效，图形本身照常绘制。右下角坐标和距离以第一个点与设备自身为准。

点击地图仍将信道值替换为**单个坐标**，不会向原数据追加点；附近点击会吸附显示点，包括线、面的顶点。游戏内帮助新增“桥接器”页签，可按章节查看全部交互模式、通用配置与可复制示例。

### DP面板

在 Dashpanels 页签底部的 **AFN Modules** 中取得模块，放到面板上，用 Panel Wrench 打开属性。频率沿用 Panel Link 为该模块提供的两个槽位。悬浮模块物品并按住 **V**，可查看其原生 Wiki 中的功能与配置说明。

#### 控制滑杆

提供标准、长型、水平和长型水平四种滑杆，尺寸分别为 3×5、3×10、5×3 和 10×3 面板像素。长型长度与大型雷达直径一致。

滑杆发送上下限之间的数值，默认范围为 0～100。开启“输出整数”后四舍五入；红石信号强度默认为 15，限制在 0～15。“改变后脉冲”默认开启：操控期间保持激活并连续更新数值，松手后用 2 tick 短脉冲交付最终值。激活条件独立生效，为真时也会保持激活；初始化、重载和配置变化不会触发改值脉冲。

- **节点**：填写 `20,50,80`、`[20,50,80]` 或信道输出语法。上下限内的节点会在刻度旁标出；拖到节点时本次拖动停止，松手后再次拖动才能越过。
- **灵敏度**：拖动变化倍率，越小越细；标准滑杆默认 1，长型默认 0.4。右键按住滑杆时可用滚轮微调，灵敏度为当前设置的一半，且忽略节点。
- **配色**：滑块、指针、刻度可分别配置，节点标记沿用刻度色。

上下限、强度、条件、节点与灵敏度支持信道输出语法。“信道输出语法”留空时发送当前数值，纯文本发送固定内容，含 `${...}` 的表达式发送计算结果。表达式无效或来源缺失时停止输出，不沿用旧值。

#### 摇杆

拖动摇杆发送二维数组 `[x,y]`。两个角点分别限定 X、Y 轴取值范围，默认 `-1,-1` 到 `1,1`；可开启整数输出。角点、强度、条件、节点与输出语法支持信道输出语法。

节点支持 `0,0`、`[[0,0],[1,1]]` 等形式，默认节点为 `[0,0]`。记忆默认关闭，松手后匀速回到最近节点；开启记忆后保留松手位置。“改变后脉冲”默认开启，操控期间持续激活并更新数值，松手后发送最终值的短脉冲。输出语法留空时保留坐标数组；可通过 `${摇杆名[0]}`、`${摇杆名[1]}` 读取自身坐标并转换输出。

#### 仪表盘与显示模块

| 模块 | 功能 |
| --- | --- |
| 扇形 / 圆形仪表盘 | 只接收单个数值；可配置名称、名称显示、上下限及背景、指针、刻度颜色。默认范围 0～100，超限时指针停在端点；圆形占用更小 |
| 小型 / 大型无线电 | 显示寻呼机对话格式的最后一条消息，包括头像、名称和正文，也接受匿名纯文本；右击清空当前消息，可配置屏幕背景与文字颜色；无消息时保持空白 |
| 小型 / 大型信息板 | 直接显示信道内容，可配置屏幕背景色和文字颜色 |
| 按钮 / 开关 / Push Button | 可设置名称、信道内容与信号强度，内容与强度支持信道输出语法。按钮短按发脉冲、按住持续发送、松开停止；开关与 Push Button 点击切换持续发送状态。按钮还可设置按压部件颜色 |
| 占位信道元件 | 接收内容和强度，供同一面板网络内的表达式按名称引用；占用 1×1 面板格，可配置颜色 |

颜色填写 `RRGGBB` 或 `#RRGGBB`。接收模块在信号结束后保留最近内容；仪表盘隐藏名称不影响按名称引用，动效沿用 Dashpanels 本体。

#### 雷达与液晶能柱

雷达分普通和大型，以模块世界位置为圆心显示目标，不绘制地形或自动缩放。支持单个世界坐标 `x,y,z`、三项一组的扁平数组、多维坐标数组，以及桥接器地图的点、线、面 JSON；配置旋转、比例尺、背景、格网、点和固定点配色。比例尺须为正数，默认显示半径为 64 格。

液晶能柱普通尺寸为竖向 1×4、水平 4×1，长型为竖向 2×10、水平 10×2，均为分节电池柱。接收单个数值，上下限默认 0～100，超限按端点显示。两个节点划分低、中、高三个区间，填充色默认依次为**红、黄、绿**；节点留空时三等分。上下限与节点支持信道输出语法，三段颜色分别设置；信号结束后保留最近数值。

#### 按名称引用

以模块名称作为信道名，可读取同一面板网络中 AFN 模块的值。范围包含合并底座上的全部模块及通过线缆连接的面板，名称须彼此不同。原生模块没有信道内容，只提供信号强度，多路模块取各路输出的最大强度。例如：

```text
${滑杆名}
${strength($.开关名)}
```

上下限须为有限数字且下限不大于上限；条件须得到布尔值，表达式无效时停止输出。游戏内仅在加载 Dashpanels 后显示该帮助章节。

### 便携式地图信道终端

便携式地图终端用于收发坐标、收藏、实体 / 敌对目标和持续广播，可在手持、讲台、导航台与 Create 置物板上工作。实体显示排除设备自身，避免与自身箭头重叠。

### 隐藏式信道终端

手持配置器右击方块面创建 / 编辑，潜行右击移除；鉴权板权限照常检查。中键复制配置，潜行中键退出复制。不能为 AFN 设备建立隐藏面。

接收面**弱激活宿主方块，不充能相邻方块**；堵住面不影响无线接收。配置随活塞、Create 动态结构和 Sable 移动，永久破坏宿主才删除。它默认自动输出，可写显示器、机器和已安装的动态过滤器。

### 信道寻呼机

寻呼机在物品栏、讲台与置物板上工作。各信道独立保存频率、名称、头像、铃声、循环上限和常用语。未读信道有红点，入站消息闪灯响铃，查看后恢复黑屏；自己发言右对齐，不点亮自己的未读小屏。右击发送头像可选择玩家头像，或按名称 / ID / 标签搜索物品图标。

手持左击点亮快捷输入，输入映射后按 Enter 或再次左击发送；同信道映射不能重复，不同信道可以相同。所有映射均为纯数字时，不占用行走按键。

桥接器对话和寻呼机共用消息格式，也接收纯文本：

```json
{"avatar":"item:minecraft:apple","name":"仓库","message":"物资已到"}
```

```json
{"name":"仓库","messages":["到货：",{"minecraft:apple":8},"请查收"]}
```

`messages` 可混排文字与多个存量对象，物资片段作为物品图标 / 数量表情包显示。玩家头像用 `player:UUID`；不符合聊天格式的内容按匿名文本显示。桥接器发送头像和名称留空时使用匿名身份。

### 蓝图与票务

蓝图信道编辑器读取 Create / Sable 蓝图中的序列化频率，包括隐藏面、嵌套物品和原生频率组。支持搜索、收纳、替换和空格编辑；已有组的空副槽可补任意频率物品，全空组不显示。鉴权页一键绑定并从玩家列表设共享权限；编辑页对主频 / 别名增改点分前后缀、全局替换。

保存生成带 `_afn_` 短标识的派生蓝图，Create 派生文件放在蓝图目录的 `afn` 子目录。服务端确认打印者时，已验证蓝图的鉴权板绑定打印者并保留 ACL；普通未验证复制清除旧身份。允许他人施工，不复制物资 / 票券库存，长信号重新检查额度。

发票机用鉴权板签发 / 解绑票券；验票机、鉴权刷卡机与身份验证柱负责验票和身份准入。板不消耗，票券是否扣留由设备模式决定。

## 电脑与控制学

CC:Tweaked 使用 `afn_bridge` 外设或内置模块，按 GUI 的实际信道名访问：

```lua
local afn = require("afn")
for _, channel in ipairs(afn.channels()) do
  print(channel.name, channel.primary_frequency)
end
assert(afn.set_value("通知", "列车即将进站").success)
assert(afn.pulse("通知", 15, 20).success)
```

读取、激活、配置权限独立管理。Lua 可读写值、激活、订阅事件、调整屏幕矩形与交互配置，不能伪造鉴权板 Owner / ACL / 隐藏身份。旧 `auth` 副频和临时附加鉴权参数是兼容入口，不代替当前 GUI 的真实鉴权板槽。

Synaxis 为信道提供激活输入、值输入和值输出，支持相应的 Real、Boolean、Vec3、Quaternion 格式，接线两端须一致。红石绑定按屏幕前后左右上下选择，可指定强度或全强度。
